# Amazon-Sales-Data-Analytics-Project


This project analyzes Amazon product data to understand pricing, discounts, ratings, reviews, and product categories. It was completed as part of my Data Analytics Internship.

## Project Tasks

- Product Segmentation using K-Means Clustering
- Discount & Rating Relationship Analysis
- Review Sentiment Analysis
- Product Ranking
- Anomaly Detection
- Product Rating Prediction using Machine Learning

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- SciPy
- Statsmodels
- NLTK / VADER

## Key Results

- Identified 3 major product segments using K-Means.
- Found a weak negative relationship between discount percentage and ratings.
- Classified customer reviews into positive and negative sentiment.
- Created a weighted Top-10 product ranking system.
- Detected anomalies using IQR and Isolation Forest.
- Built Linear Regression and Random Forest models for rating prediction.

This project demonstrates a complete data analytics workflow, including data cleaning, exploratory analysis, statistical testing, clustering, sentiment analysis, anomaly detection, ranking, and machine learning.
